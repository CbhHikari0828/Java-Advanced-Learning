# chapter01_thread_foundation 学习笔记

## Runnable 的理解

`Runnable` 表示的是任务，而不是线程；它把“要执行的任务”和“执行任务的线程”解耦了。

## Callable / FutureTask 的理解

`Callable` 表示有返回值的任务，`FutureTask` 把它包装成线程可以执行的任务，并通过 `get()` 等待和获取结果。

## 线程状态的理解

线程创建后但未启动是 `NEW`；调用 `start()` 后进入 `RUNNABLE`；调用 `sleep(...)` 这类带时间等待的方法会进入 `TIMED_WAITING`；`run()` 执行结束后进入 `TERMINATED`。
